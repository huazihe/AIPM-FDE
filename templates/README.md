# 五份交付模板

这些模板对应同一条客户交付主线。它们用于帮助思考、记录证据和交接责任；按项目范围保留有意义的字段，不必为填满表格制造信息。

| 阶段 | 模板 | 核心产物 |
|---|---|---|
| 公开资料调研 | [01 调研简报](01-research-brief.md) | 业务底图、来源、未知与访谈假设 |
| 客户需求整理与诊断 | [02 诊断卡](02-diagnosis-card.md) | 客户角色、流程、QA、需求与下一证据动作 |
| Ontology 与解决方案 | [03 业务模型](03-ontology-spec.md) | 对象关系图、字段表、规则表与方案分工 |
| POC 验证与落地交付 | [04 POC 章程](04-poc-charter.md) | 有限验证、评估、异常、工程交接与结论 |
| 持续迭代与产品回流 | [05 采用与回流记录](05-adoption-feedback.md) | 使用证据、反馈分类、痛点库与方案库候选 |

学习时将所需模板复制到本地 `.learning/outputs/`，再填写自己的练习。模板原文件保持空白，方便下一次复用。完成一份后回看前一步：新证据推翻旧判断时，更新状态并保留来源和变更理由。

公开仓库只保存空白模板和 [教学案例](../cases/manufacturing-quote/brief.md)。**不要在公开仓库填写或提交真实客户资料。** 即使使用客户代号，内部链接、经营数字、原话和独特事件仍可能识别客户；这类内容放在获授权的私有工作区。练习文件本地保存不等于已经获得外部发布许可。
